# Bug Summary

This file is the index for the OS bug tracker.

Detailed descriptions live in the range files (`bugs_001-025.md`, `bugs_026-050.md`, etc.).

## States

- **OPEN** — confirmed bug, not fixed.
- **IN PROGRESS** — currently being worked on.
- **FIXED** — implementation has been changed, but final verification is not yet recorded.
- **VERIFIED** — implementation has been changed and the relevant behavior has been verified.
- **WONTFIX** — intentionally not going to be fixed.
