# Bugs 026–050

## BUG-026 — E820 extended attributes and entry validity are ignored

**State:** OPEN  
**Severity:** Significant  
**Component:** Bootloader / PMM / E820

`mem_map_start` and `pmm_init` do not validate returned signatures, entry sizes, or disabled-region attributes.

---

## BUG-027 — E820 buffer has no capacity limit

**State:** OPEN  
**Severity:** Significant  
**Component:** Bootloader / E820

`mem_map_start` keeps incrementing `DI` without preventing the memory map from overwriting other memory.

---

## BUG-028 — Scheduler sleep arithmetic and tick comparisons can overflow

**State:** OPEN  
**Severity:** Significant  
**Component:** Scheduler / Timer

The earlier sleep-duration issue covered 32-bit overflow when multiplying milliseconds by timer frequency. That multiplication was changed to use 64-bit arithmetic, but wake-time addition and wraparound-aware tick comparisons remain unresolved.

This consolidates the earlier sleep-arithmetic item with the broader tick-counter wraparound item.

---

## BUG-029 — User `FS`, `GS`, and other segment registers can be corrupted on interrupts

**State:** OPEN  
**Severity:** Significant  
**Component:** Interrupts / User Mode

`isr_common_stub` saves only `DS` but restores all data segment registers from it.

---

## BUG-030 — `kfree()` does not validate heap ownership or allocation state

**State:** OPEN  
**Severity:** Significant  
**Component:** Heap

`kfree` accepts arbitrary pointers, stale pointers, and already-free blocks if the preceding memory happens to contain the expected magic value.

---

## BUG-031 — Heap growth has no reserved virtual-address ceiling

**State:** OPEN  
**Severity:** Significant  
**Component:** Heap / Paging

`kmalloc` can grow into regions intended for user mappings or other special mappings.

A reported reproduction was `alloc 50000000` followed by a test that crashes because the current page directory maps only about the first 4 MiB; the larger allocation reaches an unmapped region. That report is treated as a symptom/reproduction of this bug rather than a separate bug ID.

---

## BUG-032 — Extended PS/2 scancodes are mishandled

**State:** OPEN  
**Severity:** Significant  
**Component:** Keyboard Driver

`keyboard_handler` does not handle `0xE0` prefixes, so arrow and other extended keys are misinterpreted.

---

## BUG-033 — Calculator can trigger signed division overflow

**State:** FIXED  
**Severity:** Significant  
**Component:** Shell / Calculator

The calculator checked division by zero but not `INT_MIN / -1`, which can raise `#DE`.

**Original fix noted:** 2026-09-19.

---

## BUG-034 — `time` command hard-codes 100 Hz

**State:** FIXED  
**Severity:** Significant  
**Component:** Shell / Timer

The `time` command ignored the configurable PIT frequency.

**Original fix noted:** 2026-09-19.

---

## BUG-035 — PMM bitmap shifts use signed `1`

**State:** FIXED  
**Severity:** Significant  
**Component:** PMM

`set_bit` and related bitmap operations previously performed `1 << 31` using signed `1`, which is undefined behavior in C.

**Original fix noted:** 2026-09-18.

---

## BUG-036 — A20 enable failure is ignored

**State:** OPEN  
**Severity:** Significant  
**Component:** Bootloader

`bootloader.asm` does not check the BIOS call's carry flag or provide a fallback when enabling A20 fails.

---

## BUG-037 — Header changes do not reliably trigger recompilation

**State:** FIXED  
**Severity:** Build  
**Component:** Make

The previous `Makefile` did not generate dependency files, so changing a header did not reliably cause dependent object files to be rebuilt.

---

## BUG-038 — Scheduler test is timing-dependent

**State:** OPEN  
**Severity:** Build / Test  
**Component:** Scheduler Tests

`test_scheduler` assumes a fixed PIT rate and exact scheduling timing.

---

## BUG-039 — Page-table reclamation test dereferences a reclaimed recursive mapping

**State:** OPEN  
**Severity:** Build / Test  
**Component:** Paging Tests

`test_page_table_reclamation` accesses `page_table` after the final page-table mapping may have been removed.

---

## BUG-040 — Assembly boundary pointer subtraction is not a valid C object relationship

**State:** OPEN  
**Severity:** Build / Test  
**Component:** User Test / Assembly

`launch_user_test` subtracts independently declared assembly symbols as if they belonged to one C array.

---

## BUG-041 — PID allocation has no wraparound policy

**State:** OPEN  
**Severity:** Significant  
**Component:** Scheduler / Tasks

`create_task` eventually wraps `next_pid` to zero, colliding with the kernel task PID.

---

## BUG-042 — E820 entry overlap is not checked in `pmm_init()`

**State:** OPEN  
**Severity:** Significant  
**Component:** PMM / E820

The E820 map is assumed to be well-formed, but overlapping entries can occur on real hardware. The current test environment has not reproduced this condition.
